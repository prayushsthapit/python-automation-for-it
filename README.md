# 🐍 Python Automation for IT

> 🚧 **Status:** Planned — scripts will be added here as they're built.

Python scripts that automate repetitive IT support tasks.

## Planned scripts
- **bulk-user-setup.py** — create AD/local users from a CSV file
- **log-parser.py** — scan Windows Event / syslog exports for error patterns
- **health-report.py** — collect disk, memory, and service status into a daily report
- **ticket-triage.py** — categorize incoming ticket subjects by keyword

## Goals
- Reduce manual, repetitive support work through automation
- Build scripting fluency for support engineering roles
